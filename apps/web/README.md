# Volière Manager — Web

Application Vite + React (visualisation des cages, Firestore temps réel).

## Prérequis

À la racine du monorepo `voliere-manager/` :

```bash
npm install
```

Puis configuration Firebase dans `apps/web/.env.local` (préfixe `VITE_FIREBASE_*`).

## Scripts

Depuis `apps/web/` :

```bash
npm run dev
npm run build
npm run preview
```
